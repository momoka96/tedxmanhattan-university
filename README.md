# TEDxManhattan University Website

This is a free, responsive static website template.

## Edit the placeholders
Open `index.html` and replace:
- Event date
- Theme
- Speaker names
- Team names
- Registration link
- Instagram link
- Venue/directions link

## Publish for free with GitHub Pages
1. Create a free account at GitHub.
2. Create a new **public** repository named `tedxmanhattan-university`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a free `github.io` website address.

No hosting payment is required.
